Unsolved Rune Transitions

Every pair of consecutive runes in the unsolved Liber Primus sections (segments 7–15, pages 15–70), read as one continuous stream with word gaps ignored. The model being tested: a rune almost never follows itself, and every other rune is equally likely next, in proportion to how common it is.

State machine

Each rune is a state; every arrow is one transition. Self-loops sit outside the ring: the dashed loop is how many repeats independence would predict, the solid loop is how many there are. Select a rune to see its outgoing edges, coloured by how far each is from the model.

Transition matrix

Row = this rune, column = next rune. Colour is the standardised gap from the model, (observed − expected) / √expected. The diagonal is compared with what independent runes would give.

Do the words split into two populations?

If most words were filler made differently from the real words, a two-group model should fit the real words better than it fits the same runes shuffled at random between words (word lengths kept). It does not: the real words are, if anything, more uniform than shuffled text.
