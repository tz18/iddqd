# The whole key in words: "The solved book is the key: its running GP sum, mod 29, multiplies each rune.
#  Runes are numbered 1-29, so EA (29) is 0 and passes; the key waits on it. Each rune carries what came before.
#  The word lengths of each clause are put in the order of their key values."

book          = lp_solved    # all solved LP plaintext in page order (lp_common: segments with solved=True), 2977 runes, starting A WARNING BELIEVE NOTHING ...
key_stream    = gp_running_sum  # K_t = (GP(B_0) + ... + GP(B_t)) mod 29 over the book runes B_t; zero values passed over
book_offset   = 0            # start at the first rune of the book
key_pause     = EA           # the key index does not advance on a plaintext EA (it is multiplied by nothing: y = 0)
inner         = multiply     # y_i = n_i * K_j mod 29
chain         = autokey      # c_i = c_{i-1} + y_i mod 29, c_{-1} = 0, one chain through the whole text; ciphertext rune number = c (0 -> EA)
iv            = 0
breaks        = keyed_length_transposition  # clause breaks kept; inside each clause of m words, the m word lengths are written
